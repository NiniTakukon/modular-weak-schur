## 从实验到证明

| 时间或阶段 | 观察与决定 |
| --- | --- |
| 19:14–19:16 | 查阅论文，区分普通与弱版本，确定单色问题。并行助手只筛选图论候选和检查本地工具。 |
| 19:16 | 首次枚举覆盖 $3\le n\le15$、$2\le\ell<n$，共 91 组。$n=\ell+1$ 出现步长 2，$n\ge\ell+2$ 出现完整整数区间。选题后的首次实验已在五分钟内产生实质进展。 |
| 发现后 | 由全体之和减去未选数和两倍右端，证明恰有一个空位时区间连续。保留旧构型或整体加一，得到所有更大区间。比较中心左右相邻的两个倍数，得到阈值。 |
| 正式复核 | 对原始支集枚举 196 个 $(n,\ell)$ 实例，对模剩余类做独立动态规划得到 8,192 个阈值。Lean 从最小连续实例 $(n,\ell)=(4,2)$ 出发，分别对区间长度和正项个数归纳，得到同一谱定理。 |
| 原命题审核 | 用两个方向的证明把 Lean 的递推关系还原成互异自然数列表、另选右端和余数相等。对所有正参数证明“无解当且仅当 $n\le W$”以及 $W$ 的最大性。审计还打印了定义，便于检查量词及参数顺序。 |

初次枚举是发现工具。两个数学证明都给出了区间中每个整数可达的论证。正式 Lean 工程和 Python 均独立于外部求解器。边界 $\ell=1$ 单独处理，此时差值 0 永远不可达。
